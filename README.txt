
# 🗳️ Online Voting System

A secure web-based voting system built with PHP and MySQL that allows voters to register, contestants to participate, and administrators to manage elections and publish real-time results.

## 🚀 Features

- Voter registration
- Contestant registration
- Secure vote casting
- Admin dashboard
- Real-time election results
- MySQL database integration

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3

## 📂 Project Structure

online_voting_system/
├── admin/
├── image/

├── vote.php
├── results.php
└── style.css

## ⚙️ Installation

1. Clone the repository.
2. Copy the project into the `htdocs` folder in XAMPP.
3. Import the SQL database into phpMyAdmin.
4. Update the database credentials in `db.php`.
5. Start Apache and MySQL.
6. Open `http://localhost/online_voting_system`.
